# 《数据科学与数据分析》课程网站首页样例

这是一个零依赖的静态网站样例，用于验证“网站能被教师从校外直接访问”这一最小目标。

## 文件

- `index.html`：首页结构和文字
- `styles.css`：页面样式及移动端适配
- `app.js`：导航菜单和智能体界面演示

智能体区域目前只是前端交互样例，没有连接真实大模型，也不会向外部发送数据。

## 本地运行

不要直接双击 HTML 作为最终测试。进入本目录后运行：

```powershell
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。如果系统命令是 `py`，则使用：

```powershell
py -m http.server 8000
```

## 部署

详细流程、验收标准和两周计划见上一层目录中的《学生前端部署任务书_V3.2_GitHub与中国大陆云服务器.md》。

## 第一阶段限制

- 不把大模型 API Key 写进 `app.js` 或任何浏览器可下载的文件。
- 不上传学生名单、成绩、作业等个人信息。
- 不在未授权服务器上开启额外端口或自行修改学校防火墙。
- 首次验收只要求静态首页可通过 HTTPS 稳定访问。
